# Hardware

Board files and hardware notes for the WHAM controller board. Nothing is stored here yet.

Today the pin map lives with each firmware project (`firmware/<product>/docs/pin_mapping_v4.csv`; XREX adds a column of its own
signal names) and the firmware, SOP and command reference point at it. Moving it here (one pin map for the board, product columns
beside it) is the natural next step, together with the KiCad project, the bill of materials and a changelog of board revisions.
