ECH power waveform

Draw the forward power you want, then save the CSV and run python ech_compensate.py <file>.csv. The first run writes a first-shot frequency profile; each run after a shot writes the next one.

Click to add a point · drag to move · right-click or Del deletes the selected point · click a segment (or G) to switch it between output and an off gap · the shaded band after each pulse start is the rise (~2 ms) that cannot be shaped · maximum 15 ms.
